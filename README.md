## 1. 비개발자용 기능 목록

> **대상:** 기획자, PM, 비개발 직군
>
> 아래는 "로또 발매기"에 대한 기능 체크리스트입니다.

- [x] 사용자는 로또 구입 금액을 입력할 수 있다. (1,000원 단위)
    - 예:
    ```
    구입금액을 입력해 주세요.
    8000
    ```
- [x] 입력 금액에 따라 해당 개수의 로또가 자동으로 발행된다. (1장당 1,000원)
- [x] 각 로또는 1~45 사이 중복 없는 6개의 숫자가 오름차순으로 출력된다.
    - 예시:
    ```
    8개를 구매했습니다.
    [8, 21, 23, 41, 42, 43]
    [3, 5, 11, 16, 32, 38]
    ...
    ```
- [x] 사용자는 당첨 번호 6개를 입력할 수 있다. (쉼표로 구분, 중복 불가)
    - 예:
    ```
    당첨 번호를 입력해 주세요.
    1,2,3,4,5,6
    ```
- [x] 사용자는 1개의 보너스 번호를 입력할 수 있다.
    - 예:
    ```
    보너스 번호를 입력해 주세요.
    7
    ```
- [x] 구매한 로또와 당첨 번호, 보너스 번호를 비교하여 등수별 당첨 개수 및 등수별 금액을 출력한다.
    - 예시:
    ```
    3개 일치 (5,000원) - 1개
    4개 일치 (50,000원) - 0개
    5개 일치 (1,500,000원) - 0개
    5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
    6개 일치 (2,000,000,000원) - 0개
    ```
- [x] 전체 구매 금액 대비 수익률을 소수점 둘째 자리에서 반올림하여 출력한다.
    - 예:
    ```
    총 수익률은 62.5%입니다.
    ```
- [ ] 잘못된 입력값이 들어오면 "[ERROR]"로 시작하는 에러 메시지를 출력하고 해당 부분부터 재입력이 필요하다.

## 2. 개발자용 상세 기능 목록

> **대상:** 함께 구현할 개발자  
> 기능별 계층 구조를 가진 상세 체크리스트

### 프로그램 전체 구조

- [x] `Application` 클래스의 `main()`에서 프로그램이 시작된다.
- [x] 입력 처리에 `camp.nextstep.edu.missionutils.Console`을 사용한다.
- [x] 랜덤 값 추출에 `camp.nextstep.edu.missionutils.Randoms.pickUniqueNumbersInRange()`를 사용한다.
- [ ] `System.exit()`를 호출하지 않는다.
- [ ] `build.gradle`을 수정하지 않는다.

***

### 입력 단계

- [x] "구입금액을 입력해 주세요." 출력 후 입력값 검증
    - [x] 1,000원 단위로 나누어 떨어지지 않는 경우 예외 발생
    - [x] 0/음수/비숫자 입력 시 예외 발생
- [x] "당첨 번호를 입력해 주세요." 출력 후 입력값 검증
    - [x] 1~45의 범위, 중복 불가
- [x] "보너스 번호를 입력해 주세요." 출력 후 입력값 검증
    - [x] 1~45의 범위, 당첨 번호와 중복 불가

***

### 로또 발행 로직

- [x] 구입 금액을 1,000으로 나눠 그 만큼 로또 자동 발행
    - [x] 각 로또는 1~45 사이의 중복 없는 6개 번호
    - [x] 로또 번호 오름차순 출력

***

### 결과 출력

- [x] 각 등수 별 당첨 개수(5개+보너스 포함, 금액별) 출력
- [x] 전체 수익률 계산, 소수점 둘째 자리 반올림, 백분율로 출력
- [x] 출력 형식 요구사항 일치(띄어쓰기 등 포함)

***

### 테스트 요구사항

- [x] JUnit5 + AssertJ로 기능 단위 테스트 작성
- [x] 정상 입력·정상 결과 확인
- [x] 잘못된 입력(범위/중복/비숫자/공백 등) 시 예외 확인
- [ ] Random값 등 테스트 시 Mock/Stub 활용

***

- [ ] 한 함수(메서드)는 한 일만 한다
- [ ] 인덴트(depth)는 최대 2단계
- [ ] 3항 연산자 및 else/switch/case 금지, if-return 분기 사용
- [ ] Java 코드 컨벤션 준수
